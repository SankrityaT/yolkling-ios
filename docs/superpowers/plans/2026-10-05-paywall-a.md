# Paywall Variant A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the look of the shipping yolkling+ paywall with the founder-approved variant A (the creature and its glow lead), keeping every piece of purchase logic and App Store compliance it has today.

**Architecture:** `PlusView` keeps its state, purchase, restore, dialogs, unavailable state and legal footer. Only the presentation changes: a before/after hero of the player's own creature, three perk tiles, two large plan cards, and a promise card. Two helper views used by the mockup (`CoinPile`, `GlintBurst`) move from DEBUG-only design code into the design system so Release can use them.

**Tech Stack:** SwiftUI, Swift 6 (MainActor default isolation), RevenueCat, XcodeGen, Swift Testing.

**Spec:** `docs/superpowers/plans/2026-10-05-yolkling-1.1-index.md` (plan 1), the mockup `Yolkling/Features/DesignPreview/PaywallRedesignPreview.swift` lines 1-241 and screenshot `docs/design/1.1/17-paywall-a.png`, both on local branch `design/1.1-mockups` (commit 650808c).

## Global Constraints

- Two plans only, yearly then monthly. No lifetime option in this plan.
- Prices, periods, per-month figures and "save N%" come only from `SubscriptionStore.Plan`, never typed in.
- Guideline 3.1.2 elements stay: each plan's price and period visible, `renewalTerms` text, Restore Purchases, a link labelled exactly `Terms of Use (EULA)` to `YolklingURLs.terms`, a link labelled `Privacy Policy` to `YolklingURLs.privacy`, all three on one line (`.lineLimit(1).minimumScaleFactor(0.8)`).
- The `RevenueCatConfig.isTestStore` red banner stays.
- No trial, timer, review, user count or invented discount.
- Copy lowercase, no exclamation marks, no em dashes.
- Release must not reference anything under `Yolkling/Features/DesignPreview/`.

## Review Focus

- **Offering not loaded yet:** `store.plans` is empty for a moment on open. Expect the plan cards to be absent (not "$0.00"), and the CTA subtitle to read "loading…".
- **Only one package returned:** a routine RevenueCat misconfiguration. Expect the single plan card to show with its real price, not the whole picker to vanish.
- **Already a supporter:** expect the hero to show the creature glowing on both sides or a single glowing creature, and the thank-you line instead of the buy button, as today.
- **Store unavailable:** expect the existing "the supporter tier isn't available right now" block with "try again", unchanged.
- **Small phones (iPhone SE, 375pt wide):** expect nothing clipped; the content scrolls and the footer stays pinned.

```swift
import SwiftUI
import YolklingCore

/// What one plan card says, worked out from the store's own numbers and nothing else.
struct PlusPlanText: Equatable {
    let title: String
    let price: String
    let period: String
    let footnote: String
    let badge: String?

    static func make(_ plan: SubscriptionStore.Plan) -> PlusPlanText {
        let period = plan.isAnnual ? "a year" : "a month"
        // perMonth arrives as "$2.92 / mo"; the card reads it as a sentence.
        let perMonth = plan.perMonth?.replacingOccurrences(of: " / mo", with: " a month")
        let footnote = perMonth ?? (plan.isAnnual ? "billed yearly" : "billed monthly")
        let badge = plan.isAnnual ? plan.savingPercent.map { "save \($0)%" } : nil
        return PlusPlanText(title: plan.title, price: plan.price, period: period,
                            footnote: footnote, badge: badge)
    }
}

/// One plan. The selected state is unmistakable: ink stroke, warm fill, a filled tick.
struct PlusPlanCard: View {
    let plan: SubscriptionStore.Plan
    let selected: Bool

    var body: some View {
        let t = PlusPlanText.make(plan)
        VStack(alignment: .leading, spacing: 4) {
            HStack {
                Text(t.title)
                    .font(YolkType.bodySmall.weight(.semibold)).foregroundStyle(YolkColor.inkSoft)
                Spacer()
                ZStack {
                    Circle().strokeBorder(selected ? YolkColor.ink : YolkColor.line, lineWidth: 1.5)
                        .background(Circle().fill(selected ? YolkColor.ink : .clear))
                        .frame(width: 22, height: 22)
                    if selected {
                        YolkGlyph(kind: .check, size: 11, weight: 0.16)
                            .frame(width: 11, height: 11).foregroundStyle(YolkColor.shell)
                    }
                }
            }
            HStack(alignment: .firstTextBaseline, spacing: 4) {
                Text(t.price).font(YolkType.display(28, .heavy)).foregroundStyle(YolkColor.ink)
                    .lineLimit(1).minimumScaleFactor(0.7)
                Text(t.period).font(YolkType.bodySmall).foregroundStyle(YolkColor.muted)
            }
            Text(t.footnote)
                .font(.footnote.weight(selected ? .semibold : .regular))
                .foregroundStyle(selected ? Color(hex: 0x9A6F12) : YolkColor.muted)
        }
        .padding(.horizontal, 16).padding(.top, 16).padding(.bottom, 14)
        .frame(maxWidth: .infinity, alignment: .leading)
        .background(selected ? Color(hex: 0xFFF3D4) : YolkColor.shell2.opacity(0.55),
                    in: RoundedRectangle(cornerRadius: 20))
        .overlay(RoundedRectangle(cornerRadius: 20)
            .strokeBorder(selected ? YolkColor.ink : YolkColor.line, lineWidth: selected ? 2.5 : 1))
        .overlay(alignment: .topLeading) {
            if let badge = t.badge {
                Text(badge)
                    .font(.system(size: 11, weight: .bold, design: .rounded))
                    .foregroundStyle(YolkColor.shell)
                    .padding(.horizontal, 9).padding(.vertical, 3)
                    .background(YolkColor.yolkDeep, in: Capsule())
                    .offset(x: 14, y: -10)
            }
        }
        .accessibilityElement(children: .combine)
        .accessibilityAddTraits(selected ? .isSelected : [])
    }
}
```

import SwiftUI
import YolklingCore

/// Before and after: the purchase changes the screen you open every day, so show that.
struct PlusHero: View {
    let vibe: Vibe
    let outfit: [Cosmetic]
    let name: String?
    let isPlus: Bool

    private var caption: String {
        guard let name, !name.isEmpty else { return "glowing" }
        return "\(name), glowing"
    }

    var body: some View {
        ZStack {
            RoundedRectangle(cornerRadius: 32)
                .fill(LinearGradient(colors: [Color(hex: 0xFDF8EE), Color(hex: 0xF3E6CC)],
                                     startPoint: .top, endPoint: .bottom))
            RadialGradient(colors: [Color(hex: 0xFFE6A8).opacity(0.55), .clear],
                           center: UnitPoint(x: isPlus ? 0.5 : 0.66, y: 0.45),
                           startRadius: 0, endRadius: 170)
                .clipShape(RoundedRectangle(cornerRadius: 32))
            GlintBurst(count: 16, colors: [Color(hex: 0xFFD98A), .white, Color(hex: 0xC9A24B)], salt: 0x91)
                .frame(width: 260, height: 220)
                .offset(x: isPlus ? 0 : 60, y: -6)

            HStack(alignment: .bottom, spacing: 0) {
                if !isPlus {
                    VStack(spacing: 6) {
                        YolklingView(vibe: vibe, expression: .content, size: 66,
                                     outfit: outfit, frozenAt: YolklingView.posedT)
                            .frame(height: 104)
                            .opacity(0.9)
                        Text("today").font(.custom("DM Mono", size: 13)).foregroundStyle(YolkColor.muted)
                    }
                    .frame(width: 130)

                    Image(systemName: "arrow.right")
                        .font(.system(size: 15, weight: .bold)).foregroundStyle(Color(hex: 0xC9A24B))
                        .padding(.bottom, 64)
                        .accessibilityHidden(true)
                }

                VStack(spacing: 6) {
                    YolklingView(vibe: vibe, expression: .happy, size: 112,
                                 outfit: outfit, frozenAt: YolklingView.posedT, supporterGlow: true)
                        .frame(height: 176)
                    Text(caption).font(.custom("DM Mono", size: 13).weight(.medium))
                        .foregroundStyle(Color(hex: 0x9A6F12))
                }
                .frame(maxWidth: .infinity)
            }
            .padding(.horizontal, YolkSpace.sm)
            .padding(.bottom, 18)
        }
        .frame(height: 252)
        .accessibilityElement(children: .ignore)
        .accessibilityLabel(isPlus ? "your yolkling, glowing" : "your yolkling today, and with the supporter glow")
    }
}

/// The three real perks, each with a picture of itself.

                YolkGlyph(kind: .trust, size: 28, weight: 0.11)
                    .frame(width: 28, height: 28).foregroundStyle(YolkColor.pink)
            }
        }
    }

            art().frame(height: 46).accessibilityHidden(true)
            Text(text)
                .font(.footnote.weight(.medium)).foregroundStyle(YolkColor.inkSoft)
                .multilineTextAlignment(.center)
                .fixedSize(horizontal: false, vertical: true)
        }
        .frame(maxWidth: .infinity)
        .padding(.vertical, 10)
        .background(YolkColor.shell2.opacity(0.6), in: RoundedRectangle(cornerRadius: 16))
    }
}
